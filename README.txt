پیکسل یار — راهنمای نصب، راه‌اندازی و استفاده
==================================================

نسخه: ۱.۰.۲
سیستم‌عامل: ویندوز ۱۰ و ۱۱ (۶۴ بیتی)
اینستاگرام: instagram.com/mnabishahzamani
گیت‌هاب: github.com/mnabishahzamani-dev
ایمیل: mnabishahzamani@gmail.com

پیکسل یار یک برنامهٔ کاملاً آفلاین برای تبدیل دسته‌ای تصاویر به WebP است.
هیچ تصویری به اینترنت ارسال نمی‌شود و همهٔ پردازش‌ها روی همین دستگاه انجام می‌شود.


--------------------------------------------------
۱) نصب با فایل Setup
--------------------------------------------------

۱. فایل PixelYar-Setup-1.0.2.exe (در پوشهٔ اصلی پروژه) را اجرا کنید.
۲. اگر ویندوز پیام SmartScreen نمایش داد، روی «More info» و سپس
   «Run anyway» کلیک کنید. (نسخهٔ فعلی امضای دیجیتال تجاری ندارد.)
۳. محل نصب را انتخاب کنید و «Install» را بزنید.
۴. پس از پایان، میان‌بر «پیکسل یار» روی دسکتاپ و در منوی Start ساخته می‌شود.

نصب برای هر کاربر انجام می‌شود و نیازی به دسترسی Administrator نیست.
برای حذف برنامه: Settings > Apps > پیکسل یار > Uninstall
یا از مسیر نصب، فایل Uninstall را اجرا کنید.


--------------------------------------------------
۲) اجرای برنامه از سورس (برای توسعه‌دهنده)
--------------------------------------------------

پیش‌نیاز:
  - Node.js نسخهٔ ۲۰ یا جدیدتر (پیشنهاد: ۲۲ یا ۲۴)
  - اتصال اینترنت فقط برای نصب اولیهٔ وابستگی‌ها

مراحل:
  ۱. پوشهٔ پروژه را در ترمینال باز کنید:
     cd pixel-yar

  ۲. وابستگی‌ها را نصب کنید:
     npm install

  ۳. برنامه را اجرا کنید:
     npm start

ساخت نسخهٔ نصبی:
     npm run dist

فایل نصب در پوشهٔ dist ساخته می‌شود:
     dist\PixelYar-Setup-1.0.2.exe

نسخهٔ آمادهٔ نصب همراه پروژه در پوشهٔ اصلی قرار دارد:
     PixelYar-Setup-1.0.2.exe


--------------------------------------------------
۳) آموزش استفاده
--------------------------------------------------

۳-۱) افزودن تصاویر
  - روی کادر «تصاویر را اینجا رها کن» کلیک کنید و فایل‌ها را انتخاب کنید،
    یا فایل‌ها را با ماوس داخل پنجرهٔ برنامه رها کنید (Drag & Drop).
  - امکان انتخاب چند فایل به‌صورت هم‌زمان وجود دارد.
  - می‌توانید بعداً با دکمهٔ «افزودن تصویر» فایل جدید اضافه کنید.
  - فرمت‌های ورودی: PNG، JPG/JPEG، WebP، GIF، BMP، TIFF، AVIF
  - تصاویر متحرک (WebP و GIF) با حفظ فریم‌ها و زمان‌بندی تبدیل می‌شوند.

۳-۲) تنظیم کیفیت (تب «کیفیت»)
  - «حجم هدف»: برنامه کیفیت را خودکار طوری انتخاب می‌کند که حجم خروجی
    به حجم دلخواه شما (مثلاً ۱۰۰ کیلوبایت) نزدیک شود. اگر رسیدن به آن حجم
    ممکن نباشد، ابعاد تصویر نیز به‌طور متناسب کم می‌شود.
  - «کیفیت دستی»: عدد کیفیت WebP را خودتان انتخاب می‌کنید.
  - پس از تغییر تنظیمات، دکمهٔ «اعمال و تبدیل» را بزنید.
    تنظیمات به‌صورت خودکار ذخیره می‌شوند و در اجرای بعدی باقی می‌مانند.

۳-۳) تغییر ابعاد (تب «ابعاد»)
  - «اندازهٔ اصلی»: فقط فشرده‌سازی، بدون تغییر ابعاد.
  - «حداکثر ضلع»: بزرگ‌ترین ضلع تصویر به مقدار دلخواه محدود می‌شود
    و نسبت ابعاد حفظ می‌شود.
  - «اندازهٔ دقیق»: مثلاً ۱۰۸۰×۷۲۰.
      • با روش «جای دادن (Contain)» تصویر بدون دفرمه‌شدن داخل کادر قرار
        می‌گیرد و فضای خالی با پس‌زمینهٔ انتخابی پر می‌شود.
      • با روش «پر کردن (Cover)» کادر کامل پر می‌شود و بخش‌های اضافی
        از تصویر بریده می‌شوند.
      • محل قرارگیری تصویر در کادر را می‌توانید از بین ۹ موقعیت
        (بالا، وسط، پایین و ...) انتخاب کنید.
      • پس‌زمینه می‌تواند رنگ دلخواه یا شفاف باشد.

۳-۴) رنگ، شفافیت و اطلاعات (تب «رنگ»)
  - «حفظ شفافیت PNG»: نواحی شفاف تصویر در خروجی WebP حفظ می‌شوند.
  - «چرخش خودکار بر اساس EXIF»: جهت تصویر مطابق آنچه دوربین ثبت کرده
    نمایش داده می‌شود (پیشنهاد: روشن).
  - «مدیریت پروفایل رنگ ICC»:
      • تبدیل به sRGB (پیشنهادی): رنگ‌ها روی نمایشگرها یکسان دیده می‌شوند.
      • حفظ پروفایل اصلی: پروفایل رنگ فایل ورودی نگه داشته می‌شود.
  - «حذف متادیتا»: اطلاعات EXIF/XMP حذف می‌شود. اگر خاموش باشد،
    متادیتای اصلی حفظ می‌شود؛ توجه داشته باشید که ممکن است اطلاعات
    موقعیت مکانی (GPS) یا اطلاعات دوربین در فایل باقی بماند.

۳-۵) پردازش و حریم خصوصی (تب «پردازش»)
  - «جایگزینی فایل اصلی» (پیش‌فرض خاموش): فایل WebP در کنار فایل اصلی
    ساخته می‌شود و فایل اصلی به سطل بازیافت ویندوز منتقل می‌شود.
  - «رد خروجی بزرگ‌تر»: اگر حجم خروجی از فایل اصلی بیشتر شود،
    آن نتیجه پذیرفته نمی‌شود.
  - «پردازش هم‌زمان»: تعداد فایل‌هایی که هم‌زمان تبدیل می‌شوند (۱ تا ۴).
    مقدار پیش‌فرض برای بیشتر سیستم‌ها مناسب است.
  - «محدودیت ورودی»: سقف حجم فایل (مگابایت) و سقف ضلع تصویر (پیکسل)
    برای جلوگیری از مصرف بیش از حد حافظه. فایل‌های بزرگ‌تر با پیام
    مشخص رد می‌شوند.

۳-۶) پیش‌نمایش و ذخیره
  - در بالای صفحه، تصویر «قبل» و «بعد» با اسلایدر قابل مقایسه است.
  - کارت خلاصه، حجم خروجی، ابعاد نهایی، کیفیت و درصد صرفه‌جویی واقعی
    را نشان می‌دهد.
  - دکمهٔ «ذخیره فایل WebP» برای تصویر انتخاب‌شده و دکمهٔ «ذخیره همه»
    برای کل صف استفاده می‌شود.
  - هنگام ذخیره، یک پنجرهٔ انتخاب پوشه باز می‌شود.
  - با دکمهٔ × در هر ردیف می‌توانید تصویر را از صف حذف کنید.
  - اگر تبدیل یک فایل ناموفق باشد، پیام خطا در همان ردیف نمایش داده
    می‌شود و بقیهٔ فایل‌ها ادامه پیدا می‌کنند.


--------------------------------------------------
۴) نکات مهم
--------------------------------------------------

  - برنامه کاملاً آفلاین است؛ هیچ داده‌ای از دستگاه خارج نمی‌شود.
  - فایل‌های اصلی تا زمانی که خودتان «جایگزینی» را فعال نکنید
    تغییر نمی‌کنند.
  - در صورت فعال بودن جایگزینی، فایل اصلی حذف نمی‌شود؛
    به سطل بازیافت ویندوز منتقل می‌شود.
  - خروجی‌ها همیشه با پسوند .webp ذخیره می‌شوند.
  - تنظیمات برنامه به‌صورت محلی ذخیره می‌شود و به حساب کاربری
    یا اینترنت وابسته نیست.
  - برای تصاویر متحرک، تنظیم «اندازهٔ دقیق» روی همهٔ فریم‌ها اعمال می‌شود
    و تعداد فریم‌ها و زمان‌بندی آن‌ها حفظ می‌گردد.


--------------------------------------------------
۵) رفع مشکلات رایج
--------------------------------------------------

  • ویندوز هنگام نصب هشدار SmartScreen می‌دهد:
      More info > Run anyway
    (نسخهٔ فعلی امضای دیجیتال تجاری ندارد.)

  • برنامه باز نمی‌شود یا خطای native module می‌دهد (اجرای از سورس):
      npm install
    را دوباره اجرا کنید و سپس npm start.

  • تصویر با پیام «این فایل یک تصویر معتبر نیست» رد می‌شود:
      از سالم بودن فایل و پشتیبانی‌شده بودن فرمت مطمئن شوید.

  • فایل بزرگ رد می‌شود:
      سقف حجم یا ابعاد ورودی در تب «پردازش» را بررسی کنید.

  • رنگ خروجی با تصویر اصلی متفاوت است:
      در تب «رنگ»، «تبدیل به sRGB (پیشنهادی)» را انتخاب و دوباره تبدیل کنید.
